# Requirements

This service supports an HR manager administering employees and their salary history for an organisation of about 10,000 people. It provides paginated employee CRUD/search, compensation history with date-effective records, and read-only salary analytics. It uses a relational database, deterministic optional seed data, OpenAPI documentation, and automated tests.

Out of scope: payroll execution, taxation, currency conversion, authentication/authorisation, and free-form natural-language/SQL querying.
